# 内容整理大师

把杂乱无章的会议记录、需求文档、聊天整理粘贴进来，AI 自动读懂行业与语体，输出**逐层点开的阅读卡片 + 思维树图 + 结构化 JSON**。

- 游客可免费体验 1 次；登录后通过兑换授权码继续使用（额度跨设备通用）。

## 功能特性

- **五节点模型链路**：每个节点可单独指定模型与温度、可开关（核心压缩不可关），失败自动降级不中断
- **内容画像**：N0 先判定行业 / 领域 / 知识深度 / 表达类型，驱动后续节点按场景改写——专业内容用术语紧凑句式，口语内容降理解成本，非正式内容适度幽默；全程带「不杜撰、不改事实」硬约束
- **四种结果视图**：
  - 阅读卡片（三级折叠 + 要点类别前缀加粗）
  - 思维树图（从上往下的缩进大纲树，按分支 6 色循环配色，节点可单独收起/展开，文字自然换行不截断，层级可切换）
  - 结构化 JSON、节点日志
- **账号与额度**：手机号 / 邮箱验证码登录（OTP），卡密兑换次数，额度实时显示；游客首次可免费体验 1 次。入口收敛到**顶部右侧单行胶囊**（`游客 · 可免费体验 1 次` / `VIP · 18702103770 ｜ 无限次`），点击展开下拉面板完成登录 / 注册 / 兑换 / 退出
- **布局**：左右分栏可拖拽调整宽度，左侧操作区可收起为窄条（出结果后自动收起，点窄条展开），执行状态运行中默认单行、点击展开完整步骤
- **其他**：复制/下载 Markdown 与 JSON、文件导入（txt/md/json/csv/log）

## 五节点链路

| 节点 | 名称 | 职责 | 失败策略 |
|---|---|---|---|
| N0 | 风格识别 | 读懂原文，判定行业/领域/深度/语体，生成表达策略 | 降级为中性表达 |
| N1 | 结构抽取 | 按信息模块解析原文，抽出全部事实点 | 直接用原文进 N2 |
| N2 | 核心压缩 | 按表达策略改写为一句话主干 + 一级结论 | **不可跳过**，失败即中止 |
| N3 | 细节分层 | 每个结论下组织二级要点（带类别前缀）与三级补充 | 保留上一层结果 |
| N4 | 质量校验 | 逐条比对原文补漏纠错，检查是否有杜撰 | 保留上一层结果 |

提示词里内置 `SAFETY_RULE` 硬约束：不新增信息、不改数值/因果/时序、只优化句式与语体、术语保持原文写法、宁可朴素不牺牲准确。

## 本地运行

纯静态站点，任意静态服务器即可：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

`vendor/workbuddy-cloud-sdk.global.js` 是云服务 SDK 的本地内置版（公共 CDN 在国内可能加载缓慢），请勿删除。云服务接入配置在 `app.js` 顶部的 `PUBLIC_CONFIG`（endpoint + publishableKey，均为公开密钥，非机密）。

## 项目结构

```
index.html   页面结构（顶部：品牌 + 账号单行胶囊；左：输入/节点编排，右：卡片/树图/JSON/日志）
app.js       全部逻辑：五节点链路、内容画像、额度门禁、卡片与树图渲染
styles.css   样式
vendor/      云服务 SDK
schema.sql   云端数据库建表 SQL（3 张表 + 兑换函数，含 RLS 策略与 GRANT）
```

## 数据库

见 `schema.sql`。核心设计：

- `licenses`（授权码）对前端**零权限**，杜绝拖库；发卡走 SQL
- `redemptions`（兑换记录）：一张卡密只能被一个账号兑换一次；只能读自己的
- `usage_logs`（用量日志）：只能读写自己的
- `redeem_license(code)`：`SECURITY DEFINER` 函数，是前端唯一可以兑换卡密的入口
- 剩余次数 = 未过期兑换额度之和 − 成功用量条数

## 已知限制

额度校验在前端完成，技术用户理论上可绕过直接调用 LLM 接口。要彻底卡死需要加后端代理（Node 服务），那也是后续接入自动发卡与正规支付的同一条路。
